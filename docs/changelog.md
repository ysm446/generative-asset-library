## Unreleased / main

### 2026-08-08

- 画像に**編集画像（スタイル変換などの派生画像）**を紐づけられるようにしました。動画と同じように、1 枚の画像にぶら下がるサブアセットとして保存されます（`<アイテム>/edits/eNNN.png`）。
  - 画像プロパティの「動画を生成...」の下に**「画像を編集...」**ボタンを追加しました。編集プロンプト・ワークフロー・サイズ・Seed を指定して、生成キュー経由で ComfyUI に投げます。ワークフローは `workflows/edit/` に置いた JSON から選べます（例: Qwen-Rapid-AIO）。
  - 下段のサムネイルストリップに**「動画」「編集」のタブ**が付きました。編集タブには編集結果が並び、クリックでプロパティ（プロンプト・設定の編集、再生成、削除）を開けます。★・複数選択・Del キー・ドラッグ＆ドロップでの追加は動画と同じ操作です。画像ファイルをストリップにドロップすると編集画像として登録できます。
  - 編集パネルの**「元画像と同じ解像度」**チェック（既定オン）で、元画像のピクセルサイズをそのまま使って出力します。チェック中は Width / Height が入力できなくなります。外すと従来どおり、指定した値（空ならワークフローの値）が使われます。
  - 編集パネルでは、グリッドから画像をドラッグして**追加の参照画像**を渡せます（Qwen Image Edit のように複数の入力画像を取るワークフロー向け。ワークフローが受け取れる枚数を超えた分は使われません）。
  - 編集画像を**「独立した画像アイテムにする」**ボタンでライブラリの画像に昇格できます。昇格すると普通の画像なので、そこから動画生成・検索・シーケンス投入ができます。昇格した画像は元画像のすぐ隣に並び、元の編集画像もそのまま残ります。
  - サムネイルには編集画像の件数バッジが出ます（★付きの編集画像があれば金色）。★のみ表示の絞り込みでも、★を付けた編集画像を持つ画像が拾われます。

### 2026-08-07

- 左サイドバーのフォルダの右クリックメニュー（[…] メニュー）に**「画像を一括で出力」**を追加しました。出力先を選ぶと、その中に**選択したフォルダ名のフォルダが作られ**、フォルダ内の画像がまとめてコピーされます。子フォルダがある場合は「子フォルダ（孫以下も含む）の画像も出力する」のチェックボックスで再帰的な出力を選べます。ファイル名はアイテム ID（作成日時ベース）なので、出力先でも作成順に並びます。ライブラリの中への出力はできません。
  - 出力が終わると**右下に通知**が出て、クリックすると出力先フォルダをエクスプローラーで開けます（× か一定時間で消えます）。

### 2026-08-04

- サムネイルに**お気に入りの★**を付けられるようにしました。画像のサムネイルと、下段の動画サムネイルの右上に★ボタンがあり、クリックで切り替えられます（マウスを載せたときだけ薄く出て、★を付けると常に金色で表示）。★は `meta.json` に保存されるので、フォルダを移動してもインデックスを再構築しても残ります。
  - 選択中のサムネイルは **F キー**でも切り替えられます（複数選択していればまとめて。動画を選択中なら動画が対象）。右クリックメニューからも操作できます。
  - 検索欄の右の★ボタンで、**お気に入りだけを表示**する絞り込みができます。★を付けた画像に加えて、★を付けた動画を持つ画像も表示します（設定は次回起動時も引き継ぎます）。
  - ★付き動画を持つ画像は、サムネイルの動画バッジが金色になり★が付きます（動画ストリップを開かなくても分かります）。
- 画像ギャラリー（サムネイル一覧）で**矢印キーによる移動**ができるようにしました。カードを一度クリックしてギャラリーにフォーカスがある状態で、←→ が前後のサムネイル、↑↓ が上下の行への移動です。移動先は選択状態になり、右のプロパティパネルと下段の動画も一緒に切り替わります。画面外に出たときは自動でスクロールします（列数は表示幅に合わせて自動判定するので、パネル幅やカードサイズを変えてもそのまま使えます）。

### 2026-07-29

- Prompt / Negative Prompt でスニペットに登録済みの語を示す表示を、点線の下線から**文字色**（水色）に変更しました。ラベル横のパズルアイコンでのオン / オフはこれまでどおりです。

- Width / Height / Steps / CFG / Sampler を「画像パラメータ」としてひとまとめにし、開閉できるようにしました（生成パネルと画像プロパティの両方）。既定は閉じた状態で、閉じているときは見出しの右に現在値（例: `1024×1024 / Steps 28 / CFG 7 / Euler a`）を表示します。開閉状態はパネルごとに保持されます。
- ライブラリで画像を選択したときに、サムネイル一覧が数行ぶん勝手にスクロールすることがある問題を修正しました。カードの折り返し（右端の余り）が変わった直後に起きやすい症状でした。
- BGM の音量スライダーの見た目を、プロンプトの強調スライダーと同じ細いバー（つまみ小・左側はアクセント色）に揃えました。
- Prompt / Negative Prompt 欄で語にマウスを載せると、強調（重み）スライダーが出るようにしました。動かすとその場で書き換わり、**1.0 は括弧なし**、**1.1 は `(word)`**、それ以外は `(word:0.6)` の形になります。既にある `(word:1.2)` `((word))` `[word]` は読み取って初期値にします（`(` は 1.1 倍、`[` は 1/1.1 倍、入れ子は掛け算）。範囲は 0〜2.0（0.05 刻み）、「↺」で 1.0 に戻せます。キー入力を始めるかマウスを離すと閉じます。スライダーは細めのバー（つまみ小）で表示します。ラベル横のスライダーアイコンで表示のオン / オフを切り替えられます（設定は保持され、下線のパズルアイコンとは独立）。
- 語にマウスを載せたときのスニペットのツールチップ（登録済みの名前・説明・ファイル名）が実際に表示されるようになりました。これまで当たり判定の取り方が原因で出ていませんでした。
- シーケンス画面でキーボードショートカットを追加しました。**F** で選択中のノード（クリック / 範囲選択）にフォーカス、**A** でノード全体を表示します（テキスト入力中は無効）。
- シーケンスのノードエリア右上に「整列」ボタンを追加しました。ノードを順路の順に格子状（1 行の数は表示幅に合わせて自動、最大 10）へ並べ直します。範囲選択で 2 件以上選んでいるときは選択したノードだけが対象で、並べ始める左上の位置は元のままなので離れた場所へ飛びません。
- 下段の動画サムネイルをクリックすると、右パネルの動画プロパティで再生が始まるようにしました。Ctrl・Shift クリックでの複数選択や右クリックでは再生しません。
- 右上の Forge / ComfyUI / LLM / Embedding のチップを大きくし、クリックで起動・停止できるようにしました。停止中のチップをクリックすると起動（LLM は前回のモデル、無ければ名前順の先頭を自動でロード）、稼働中のチップをクリックすると確認のうえ停止します。起動に失敗した場合はチップが赤くなり、マウスオーバーで理由を表示します。外部プロセスを使う設定の Forge / ComfyUI はアプリから操作できないため、押せない表示のままです。
- ライブラリとスニペット編集で、保存先フォルダ（ルート）の表示と変更ボタンをサイドバーの最下部から最上部へ移動しました。
- ライブラリのフォルダツリー上部のツールバー（「＋（新規フォルダ）」「エクスプローラーで開く」）を削除しました。どちらもツリーの […] メニュー / 右クリックから実行できます。
- スニペット編集のファイル一覧上部のツールバーから「削除」「フォルダを開く」ボタンを削除しました。「削除」は各行の […] メニュー / 右クリックに、「フォルダを開く」は同メニューに追加しました（ファイルが 1 件も無いときは一覧の余白を右クリック）。「＋（新規ファイル）」はそのまま残しています。
